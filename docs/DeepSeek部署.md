# DeepSeek 服务部署

## 必须完成
1. 在微信开发者工具上传并部署 cloudfunctions/Deepseek，选择云端安装依赖；Node.js 18 或更新运行时，函数超时90秒。
2. 在云函数服务端环境变量配置 DEEPSEEK_API_KEY；可选 DEEPSEEK_MODEL，默认 deepseek-flash。密钥只在云端配置，不写入小程序、Git 或聊天。
3. 创建集合 ai_usage、club_members、club_knowledge。三者客户端读写权限全部关闭，只允许云函数服务端访问。
4. 在云控制台添加成员记录：openid（成员微信身份）、clubId（俱乐部标识）、active: true、role: member 或 admin。每个 openid 当前仅支持一个有效俱乐部。
5. 在小程序管理后台完善隐私保护指引（录音、识别文字和 AI 处理说明），发布前检查隐私授权及麦克风授权流程。
6. DeepSeek 账户需开通付费 API 并有可用余额；确认账户可调用 /v1/tools/asr 和对话模型。此版本未进行真实付费调用。

## 行为与限制
- 语音每段60秒、16kHz单声道16-bit PCM；云端包装WAV后送识别，识别文字先给用户确认再发送。无语音播报。
- 对话与草稿保存在本机；每用户每日最多100次付费请求，失败尝试也计入。额度不是全局账单预算，需在服务商另设预算告警。
- 知识库为单俱乐部授权文本参考，不是模型微调；扫描最多100条已审核资料，基于关键词选3条。适合试点，规模扩大需分页/索引/向量检索。
- 管理员可录入稿件和视频转写文字；尚不支持视频文件上传、批量转写、知识资料修改与删除界面。可在控制台管理。
- AI 请求非流式；长任务需等待。对话最多24条，长对话请整理成稿后另开。
- 再次整理会更新本对话关联稿件，并保留最近5个历史稿件版本；尚无版本恢复界面。
- 未部署或未配置不会降级为虚构响应，会显示实际失败提示。

官方依据：https://api-docs.deepseek.com/api/create-chat-completion/ 、https://api-docs.deepseek.com/guides/asr/
