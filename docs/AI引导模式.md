# AI 引导模式

- 按等级：读取 user_member_profile 的自报 G1/G2/G3，仅用于教学难度，不作为正式认证或权限。
- 通用：不按等级预设能力，随对话调整。
- 类型：自动识别、通用表达、故事演讲、工作汇报、观点说服、即兴表达。
- 自动类型在同一次教练回复中生成，不额外调用模型；手动选择优先，分类结果显示在界面。
- 设置保存在本机；修改后从下一轮回复生效，不清空已有对话。新对话保留偏好。
- 成稿请求同样带模式与类型。故事强调真实事件，汇报强调目标、结果、证据、卡点、支持与下一步。
- 发布需重新部署 Deepseek 云函数（包含 coaching.js），客户端与云端一起更新。尚需实际模型对话评测。
